# U21MI504 - Unmanned Aerial Vehicle Technology

GitHub Pages deployment files for the course's interactive Storyline modules.

## Published items

- `modules/01-uas-architecture-lab/` - UAS Systems Architecture Lab
- `modules/01-uav-history/` - History and Development of UAVs
- `quizzes/unit-1/` - Unit I Quiz
- `quizzes/unit-2/` - Unit II Quiz
- `quizzes/unit-3/` - Unit III Quiz
- `quizzes/unit-4/` - Unit IV Quiz
- `quizzes/unit-5/` - Unit V Quiz
- `resources/` - Student resources (PDF slides, simulator lab, quick-start, cheat sheets, posters). Editable sources stay in the course folder.

Each item has its own folder URL and launches independently.

## Add a new item

1. Publish the Storyline project for Web.
2. Copy the complete published output into its own folder under `modules/` or `quizzes/`.
3. Add an `index.html` redirect in that folder pointing to `story.html`.
4. Add a matching card and link in the root `index.html`.
5. Commit and push the complete site folder to GitHub.

Do not place editable `.story` files or textbook PDFs in this public website folder.
